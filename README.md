A single sentence about the best meal I ever had: cup noodles on a night bus out of Yogyakarta, salt on my lips and rain on the window. The program writes that sentence to `entry.txt` for the judge.

## Run it

```sh
node main.ts
```

`main.ts` writes the sentence to `/output/entry.txt` (override the directory with `ENTRY_OUTPUT_DIR`).
